# USCIS 2025 Civics Test — 非官方简体中文参考译文

**本项目不是美国公民及移民服务局（USCIS）的官方出版物，也不代表任何美国政府机构。**

本仓库整理了 USCIS 2025 年公民常识考试材料的简体中文学习参考译文。目前提供 **128 道题及其可接受答案**，方便普通中文读者学习美国政治制度、历史和地理常识。

**注意：** 题号后 `*` 标识官方“65/20”特别安排的20道指定题。本项目发布的是学习辅助材料。申请美国入籍时，应以 USCIS 官方最新英文资料和适用要求为准；部分现任官员及各州相关题目的答案需要动态更新。

## 项目方法与质量控制

本项目采用 AI 辅助翻译和版式处理；人工制定翻译要求，并对部分译文、排版和版权问题进行检查和修订。它不是由维护者逐字独立人工翻译的作品。

- 对照 USCIS 2025 年英文题库核对了题号及答案选项数量：**128 题，411 个答案选项，逐题数量一致**；同时核对了 **20 道星标题**。这只是结构核查，不代表全文逐项语义审校。
- 修正了第 63 题“人头税”条目的中文歧义，并修复了部分 PDF 链接提取顺序造成的文本问题。
- 提取稿不包含原教材的照片、历史地图、视觉图形或 USCIS 标志。
- **未完成每个选项的第二位人工译者逐词审校**；如发现措辞或事实问题，欢迎提交 Issue 并附英文来源。

## 为什么没有上传完整图文 PDF？

完整图文版包含原 USCIS 文档中的照片、插图和机构标志，其中部分材料来自第三方。**USCIS 公开提供原始 PDF，并不自动授予第三方重新打包、翻译及传播其中所有图片的权利。** 在确认具体授权或更换相关素材之前，不在仓库提供原版式重建 PDF。
