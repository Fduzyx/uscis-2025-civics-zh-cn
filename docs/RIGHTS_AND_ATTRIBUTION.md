# 权利、素材和出处核查说明

**本文件是非法律意见的发布风险清单；不能替代原权利人的授权。**

## 已核实的普遍原则

1. 美国《版权法》17 U.S.C. §105 通常不对美国联邦政府职务作品提供版权保护，但政府可持有受转让而取得的版权，且政府 PDF 中可能包含第三方受保护材料。
2. USAGov 明确提示：政府网站上的图片、标志、文本等可能涉及他人权利；不能仅凭材料位于 `.gov` 域名就假定可自由再发布。
3. 使用政府名称及标志不能造成官方认可、背书或合作关系的误解。
4. 原版 PDF 的图片署名意味着出处，不等于为我们的再分发行为授予授权。

## 当前公开候选版本的内容策略

- 仓库仅收录 USCIS 官方公民题库的**非官方简体中文纯文字参考稿**、链接和项目说明。
- 不打包、托管或重绘来源不明的照片、绘画、地图和政府标志。
- 不附带完整图文 PDF，即便原 USCIS 官网可以免费访问。
- 不给整个项目套用会涵盖第三方材料的宽泛 MIT / CC 授权。
